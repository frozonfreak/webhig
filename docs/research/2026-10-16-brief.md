## Scope and follow-up

The [WCAG baseline](../../rules/accessibility.md) remains unchanged. The browser release and preprint do not create WCAG conformance requirements. [Current Core Web Vitals guidance](https://web.dev/articles/vitals) continues to use LCP, INP and CLS; no threshold update is warranted by this brief. HIG's stricter aspirational targets remain separate from the external CWV thresholds.

Prioritize real-device Firefox Android/TalkBack testing for incrementally updated regions, including streamed responses. Clear busy state on every terminal path and verify that the appropriate final result, cancellation or error status is announced. Attribute inspection alone cannot establish a pass. See the linked checklist for evidence requirements and browser/AT issue triage.

This repository update records research and a manual review procedure only. It does not implement or deploy changes to the separate audit site, and no device/AT checks have been run for this review.
