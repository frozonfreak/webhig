# Web HIG research brief — 2026-11-27

Coverage is 21–27 November 2026. Web HIG v1.20.0 adds informative guidance for credential flows, resource adaptation, agent supervision, generated records, and pointer-driven motion.

| Topic | Assessment and disposition | Repository action |
| --- | --- | --- |
| Digital Credentials | **Change.** The 25 November Working Draft addresses accessible status, keyboard operation, focus, QR alternatives, and time to complete the flow. Browser, wallet, and protocol support depend on the operation. Its optional virtual wallet can exercise the page’s response handling. [W3C draft](https://www.w3.org/TR/2026/WD-digital-credentials-20261125/) | [§9.5](../../HIG.md#digital-credentials-informative) covers site-owned interactions and fallback. The [review procedure](../../examples/audit-fixtures/digital-credentials/README.md) records native chooser behavior separately. |
| Compute Pressure | **Change.** The 21 November Candidate Recommendation Draft describes accessibility priorities when apps reduce work under CPU pressure. The principle applies to any adaptation that can remove essential content. API testing is conditional on use. [W3C draft](https://www.w3.org/TR/2026/CRD-compute-pressure-20261121/) | [§6.6](../../HIG.md#66-resource-adaptation-informative) covers essential or pinned content, accessible status, and recovery. The [review procedure](../../examples/audit-fixtures/compute-pressure/README.md) covers simulated pressure and the no-signal path. |
| Agent supervision | **Change.** The preprint identifies difficulty specifying an agent’s boundaries up front and overseeing it after delegation. Treat it as a design argument. [Johal and Schombs](https://arxiv.org/abs/2611.31739) | [§7.5](../../HIG.md#75-user-visible-agent-control-boundaries-informative) adds understandable authority, progress, intervention, and execution history to product interaction review. |
| AI-generated records | **Change.** A care-work study found inaccurate and irrelevant material in summaries of real interactions. It supports review before commitment and control over captured inputs. Recording controls are specific to products that capture recordings. [Frontiers study](https://www.frontiersin.org/journals/digital-health/articles/10.3389/fdgth.2026.1972601/full) | [§7.6](../../HIG.md#76-generated-drafts-and-records-informative) covers draft status, review, source access, retention, and cancellation. |
| Pointer-driven animation | **Change guidance, defer automation.** The First Public Working Draft defines CSS and script interfaces for pointer progress timelines. The existing motion outcome applies, including when changing animation duration has no effect on pointer-linked progress. [W3C draft](https://www.w3.org/TR/2026/WD-pointer-animations-1-20261124/) | [§1.3](../../HIG.md#pointer-driven-animations-informative) covers reduced motion and equivalent access by keyboard and touch. |
| Firefox 161 | **Keep conformance, update implementation guidance.** The release notes confirm CSS `random()`, Compression Dictionary Transport, and SVG `referrerpolicy`. Check compatibility in the project matrix. [MDN release notes](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/161) | Decorative randomness needs a deterministic fallback. Measure compression savings after negotiating and caching dictionary variants. Apply a referrer policy where SVG fetches need it. |
| Filter Effects Level 2 | **Defer.** Monitor agreement and interoperability on Backdrop Root behavior. [W3C draft](https://www.w3.org/TR/2026/WD-filter-effects-2-20261124/) | Track the draft for future review. |
| WebAgents interoperability | **Defer.** The Community Group report is architectural background. [Living report](https://w3c-cg.github.io/webagents/TaskForces/Interoperability/Reports/report-interoperability.html) | §7.5 references it for background. |
| Web Platform Design Principles | **Keep.** The TAG Group Note informs permissions, trustworthy browser interfaces, and assistive-technology privacy. [TAG Group Note](https://www.w3.org/TR/2026/NOTE-design-principles-20261124/) | Layer 9 references it for design review. |

The review procedures are manual or integration checks for products that offer the relevant features. Browser and assistive-technology execution is pending. The contract has 98 Quick imperatives and 76 stable rule IDs. This update adds guidance within the existing WCAG 2.2 AA and Core Web Vitals conformance model.
